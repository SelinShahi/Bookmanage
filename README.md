Library Management System 📚
A simple Library Management System built with Python and MySQL. This project demonstrates CRUD operations, database connectivity, and basic user management.
Perfect for beginners looking to learn Python programming and project structure.

Features ✨
User registration & login system 
Add, update, delete, and view books (CRUD) 
Search books by title or author 
Simple and clear console-based interface 

Technologies Used 🛠️ 
Python 3.x
MySQL 
mysql-connector-python library 

Installation & Setup ⚙️ 
Clone the repository:
git clone https://github.com/SelinShahi/library-management.git 

Install required Python packages:
pip install mysql-connector-python
Create a MySQL database named library 
Import the tables.sql file (if exists) or manually create tables: user & book 
Run the main Python file: 
python main.py
